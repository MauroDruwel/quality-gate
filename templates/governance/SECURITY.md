# Security Policy

## Supported Versions

Only the latest release on the `main` branch receives active security updates and vulnerability patches.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| < Latest| :x:                |

---

## Reporting a Vulnerability

We take the security and integrity of our software seriously. If you discover or suspect a security vulnerability, please report it privately:

1. **Do not** open a public GitHub issue or discussion.
2. Use GitHub's private vulnerability reporting feature via the repository's **Security > Report a vulnerability** tab, or email Mauro Druwel directly at `mauro@maurodruwel.be`.
3. Provide:
   - Detailed description of the issue and potential impact.
   - Minimal reproduction steps, proof of concept (PoC), or code snippet.
   - Affected platforms or configurations.

You will receive an initial response within 48 hours, and updates on triage and mitigation progress will be provided promptly.
